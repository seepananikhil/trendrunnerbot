How to get these credentials
  • Kotak Consumer Key: Log in to the Kotak Neo Trade API portal → My Apps / API Keys → copy the Consumer Key, and whitelist this VM's static IP.
  • Kotak UCC & Mobile: Your 5-character Client Code (UCC) from Kotak Neo Profile, and registered mobile with +91 (e.g. +919876543210).
  • MPIN & TOTP Secret: Your 6-digit trading MPIN. For TOTP, enable TOTP 2FA in Kotak Neo and copy the Base32 Secret Key shown alongside the QR code.
  • Telegram Bot Token: Open @BotFather in Telegram → send /newbot → name it (e.g. My TrendRunner Bot) → copy the API token.
  • Telegram Chat ID: Open your new bot in Telegram, send /start, then click Detect above to fill your Chat ID automatically.
